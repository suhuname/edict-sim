# 三省共守 — 太子 · 中书 · 门下 · 尚书

## 审议回路

中书起草 → 门下审议

- **准奏**：门下不作状态变更，只在回话里给「准奏 + 附条件」；由中书把状态推到 Assigned 再差遣尚书。
- **封驳**：门下把状态**退回 Zhongshu**（`kanban_state("Zhongshu", …)`），并写明至少两条具体修改要求。
  中书依此改方案，再送审。**最多三轮，第三轮门下必须准奏**（系统会拒绝第三次退回）。

## 各自能做什么

| 角色 | 能做 | 不能做 |
|---|---|---|
| 太子 | 提炼要点、立册、差遣中书 | 起草方案、直接调六部 |
| 中书 | 起草方案、送审、准奏后差遣尚书、最终回奏 | 亲自写代码/做数据 |
| 门下 | 四维审议、准奏或封驳 | 自己改方案、自己派差 |
| 尚书 | 差遣六部、抽查产出、汇总、转 Review | 越权调中书改方案 |

## 状态对照

`Taizi → Zhongshu → Menxia → Assigned → Doing → Review → Done`
（封驳时 `Menxia → Zhongshu` 是唯一合法的回退）
